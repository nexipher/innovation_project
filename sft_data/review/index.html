审核要点

  • <observation> 里的每条视觉陈述，都能在图上直接核验吗？
  • <forensic_evidence> 与真实 token 一致吗（evidence_id、测量范围、原始数值、校准概率）？
  • <reasoning> 只引用了合格证据吗？反证与失效条件是否如实写出？
  • 有没有把 PNG/JPEG 容器当成真假的理由？（这是必须拒绝的错误）
  • <verdict> 与后验、与证据强度一致吗？高置信是否有证据支撑？
  • 这条轨迹相对 no-tool 基线的增益是真的吗（ΔBrier 为负且结论正确）？
  • 训练这条样本会不会教出坏习惯（格式捷径 / 无理由弃权 / 模板化）？
