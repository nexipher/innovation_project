## 结论与边界

- 每个生成器上 PROBE 的 AUROC/平衡准确率都高于 SPAI；BigGAN 上 SPAI AUROC 0.341 低于随机（0.5），不能作为稳健全局专家。
- 错误重叠显示 SPAI-only 正确数远小于 PROBE-only；没有证据支持把 SPAI 加入全局专家组。**当前全局线保留 PROBE 单独作为主检测器，SPAI 不接入。**
- 共享 Real 的组间依赖和单 dev 子集限制仍未消除；test 继续隔离、不能称为未见测试。
- MNW/DIV2K q95 是单独报告，不与 GenImage 合并；本轮没有训练/阈值拟合。
